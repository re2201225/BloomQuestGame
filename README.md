Description: 

Bloom Quest is a 2D pixel-art platformer game developed using Unity as part of the KH6002CEM Mobile App Development module. The game features two levels where players control a growing plant character that collects suns, avoids obstacles, and completes objectives to progress. 


Third-Party Plugins & Resources:

- Unity Asset Store (Free Assets)

- Pixel art tilesets and UI elements

- Background music and sound effects

- TextMeshPro: Advanced UI text rendering

- Visual Studio Code: Used for scripting in C# and Node.js


How to run:

- Download or Clone the Repository provided in the report

- Open Unity Hub

- Click on "Add Project" and select the downloaded folder

- Make sure to use Unity 2022.3 or later

- Open the Project

- Once loaded, open the SplashScreen scene from the Scenes folder

- Play the Game

- Click the green Play button in Unity Editor to start testing
